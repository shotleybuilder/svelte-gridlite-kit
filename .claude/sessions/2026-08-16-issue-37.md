# Session: Per-View Query & Aggregate Filters (#37) (CLOSED)

## Problem

Views can define filters, sorting, grouping, and column visibility — but cannot express aggregate conditions (`HAVING COUNT(*) > 1`) or use a different base query per view. A legal glossary with 49k definitions needs a "Multi-Definition Terms" view showing only terms defined across multiple laws (~2k of 12k terms), which requires either per-view SQL overrides or aggregate filter operators. An additional request is sorting by group count (`ORDER BY COUNT(*) DESC`).
