# Session: ILIKE Escape Fix (#38) (ACTIVE)

## Problem

PGLite's `live.query()` wraps SQL in PostgreSQL `format()`, which treats `%` as a format specifier. The query builder emits literal `'%'` in ILIKE patterns (e.g. `ILIKE '%' || $1 || '%'`), causing `unrecognized format() type specifier "'"` errors. All text search filters are broken with PGLite live queries.
