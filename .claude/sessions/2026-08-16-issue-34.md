# Session: defaultGlobalSearch Prop (#34) (CLOSED)

## Problem

GridLite has no `config.defaultGlobalSearch` prop to set the initial search value on mount. `applyConfig({ globalFilter })` already works for runtime updates, and `GridState.globalFilter` is already exposed in `onStateChange`. The missing piece is the initial mount value — blocking URL state persistence in sertantai-legal's screening page.
